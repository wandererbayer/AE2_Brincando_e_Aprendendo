# Modelo de declaração

A Uninter não fornece modelo pronto para esta declaração. O roteiro apenas descreve o que ela
precisa conter: os dados do aluno, os dados da instituição, a informação de que o projeto foi
aplicado de modo presencial ou remoto, a assinatura e o carimbo do responsável.

O texto abaixo cobre todos esses pontos. Imprima em papel timbrado da instituição, se houver,
ou em papel comum — o carimbo é o que identifica a instituição. Leve duas vias: uma fica com
a escola e outra com você.

Use a **versão 1** se for colher a assinatura no dia da apresentação. Use a **versão 2** se
conseguir voltar depois que as professoras já tiverem usado o site com as turmas: ela é mais
forte, porque descreve o uso efetivo com as crianças.

## Antes de imprimir

- Confira se o nome da instituição está exatamente como ela se identifica oficialmente.
- Deixe os campos de data em branco para serem preenchidos à mão no ato da assinatura:
  declaração com data preenchida antes do fato é o tipo de coisa que uma direção se recusa a assinar.
- Peça o carimbo. Sem ele, a declaração não atende à exigência do roteiro.
